# Last Ringgit

A 30-day money survival game for a first salary of RM1,500. Decisions, the report, and the rewind comparison are calculated locally. Progress stays in this browser's localStorage.

```sh
npm install
npm run dev
npm run test
npm run build
```

Deploy to Vercel by importing this repository. The default Vite build settings work: build command `npm run build`, output directory `dist`. Open `/?demo=1` for a late-month sample.
